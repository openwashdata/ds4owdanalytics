# ds4owd_browser: Data on visits to the DS4OWD website by browser

This dataset contains information on visits to the DS4OWD website by
browser used.

## Usage

``` r
ds4owd_browser
```

## Format

A tibble with 17 rows and 6 variables

- browser:

  Browser used to accesss the DS4OWD website

- pageviews:

  Number of pages viewed

- visitors:

  Total number of unique visitors

- visit_duration:

  Duration of visit (seconds)

- visits:

  Number of non-unique visits to the website

- bounce_rate:

  Percentage of users "bouncing" off website. A bounce is when a visitor
  spends less than 30 seconds on the website
