# publishing_metadata: Publishing Metadata

Metadata on packages published directly as a result of DS4OWD.

## Usage

``` r
publishing_metadata
```

## Format

A tibble with 34 rows and 14 variables

- id:

  Identifier of dataset

- pkg_name:

  Name of the package

- maintainer:

  Github ID of maintainer

- source:

  Source of data

- difficulty:

  Difficult of cleaning data

- status:

  Current status

- description:

  Description of data package

- location:

  Location of data in the package

- date_published:

  Date of publication

- link_github:

  Link to github repo

- link_pkg_website:

  Link to package website

- doi:

  Zenodo DOI of package

- temporal_coverage:

  Temporal coverage of data

- keywords:

  Keywords to identify data
