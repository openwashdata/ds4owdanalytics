# ds4owd_timeseries: Timeseries data on website traffic

Timeseries data on website traffic to the DS4OWD website

## Usage

``` r
ds4owd_timeseries
```

## Format

A tibble with 468 rows and 6 variables

- date:

  Date of data collection

- pageviews:

  Number of pages viewed

- visitors:

  Total number of unique visitors

- visit_duration:

  Duration of visit (seconds)

- visits:

  Number of non-unique visits to the website

- bounce_rate:

  Percentage of users "bouncing" off website. A bounce is when a visitor
  spends less than 30 seconds on the website
