# ds4owd_source: Data on source of website visits

Data on source of website visits

## Usage

``` r
ds4owd_source
```

## Format

A tibble with 27 rows and 6 variables

- source:

  Source of visit (Search engine, organic etc.)

- pageviews:

  Number of pages viewed

- visit_duration:

  Duration of visit (seconds)

- visitors:

  Total number of unique visitors

- visits:

  Number of non-unique visits to the website

- bounce_rate:

  Percentage of users "bouncing" off website. A bounce is when a visitor
  spends less than 30 seconds on the website
