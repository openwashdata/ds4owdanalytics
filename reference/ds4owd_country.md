# ds4owd_country: Data on visits to the DS4OWD website by country

Visits to the DS4OWD website by country

## Usage

``` r
ds4owd_country
```

## Format

A tibble with 88 rows and 6 variables

- country:

  Country of visit to the website

- pageviews:

  Number of pages viewed

- visit_duration:

  Duration of visit (seconds)

- visitors:

  Total number of unique visitors

- visits:

  Number of non-unique visits to the website

- bounce_rate:

  Percentage of users "bouncing" off website. A bounce is when a visitor
  spends less than 30 seconds on the website
